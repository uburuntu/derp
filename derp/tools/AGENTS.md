# Tools

Plain capabilities behind the agent's utility tools (`derp/agent/tools/utilities.py`); no aiogram or Pydantic AI here.

- `lookups.py`: `Lookups`, one shared HTTPX client created and closed by `Services`. Keyless public APIs (Open-Meteo, CoinGecko, open.er-api.com, Wikipedia, Urban Dictionary, arXiv) plus WolframAlpha and JDoodle when their keys are configured.
- Every call has a deadline and a response-size cap and returns compact text for the model; slow-moving answers are cached in memory for a few minutes.
- Failures raise `LookupError` whose `reason` is safe to show (an exception class or HTTP status, never URLs, queries or bodies). Nothing here logs requests.
- Keys are sent only to their own service.
- Media effects: `workers.py` is the local CPU pool (slots and queue, then "busy"; input and output size, pixels and deadline — all from `settings.media`, the pool built once by `derp.app` and passed to every effect) and the killable subprocess runner (deadline, stdout cap, native diagnostics discarded). `effects.py` turns bytes into memes (image and video), reversed clips/voice, mirrored pictures, frames, audio samples and OGG/Opus (`speech`: the speech track for transcription, Derp's voice messages; `SilentError` when a file has no audio stream) via ffmpeg (static WebP stickers via Pillow, `captions.sticker`), which reads only local files of whitelisted containers and never sees user text. `captions.py` draws captions with Pillow (demotivator, Lobster, white panel) using the bundled OFL fonts in `fonts/`, and encodes every static sticker (`encode_sticker`). `quotes.py` draws Telegram-looking quotes from plain data (`Quoted`: name, peer colour, text with UTF-16 entities, avatar and media bytes, reply bar), grouped by sender, laid out at 1× then drawn at twice the output density and scaled down; a sticker only while its body text stays readable at sticker size (`STICKER_TEXT`), else a PNG picture on a backdrop matching the bubble colour; Noto Sans (Latin + Cyrillic subset, OFL) is bundled, colour emoji come from the image's Noto Color Emoji (text font in dev); unreadable pictures fall back to initials or nothing; `effects.quote` runs it in the pool. `background.py` runs U²-NetP on CPU in its own rlimited process; its weights are fetched and checksum-verified at image build (`python -m derp.tools.background fetch PATH`), never during a request.
- `Lookups` also identifies songs (ACRCloud, signed with the configured keys) and anime scenes (trace.moe).
- `timezones.py`: IANA time-zone names (`iana` canonicalizes what the model wrote) and conversion (arithmetic is the agent's Python sandbox, see `derp/agent/tools/code.py`).
- Tests inject an `httpx.MockTransport`; e2e journeys serve canned JSON through the `web` fixture and fail everything else like an outage.
