# Ops

- `observability.py` is the only module that configures logging or Logfire. Spans carry numeric IDs, kinds, counts and outcomes; never message text, captions, tool arguments, file IDs, URLs or exception messages. The one exception is `record_run_failure`, which exports a redacted, truncated exchange. `record_decision` logs one event per pre-run decision call (outcome, duration, probabilities and the chosen effort).
- Logfire is optional and must fail soft. Do not instrument HTTPX/aiohttp globally — Telegram file URLs contain the bot token.
- `redaction.py` masks known secrets (from `Settings.secret_values()`) and secret-shaped strings in every log line.
- `feedback.py` + `models.py` (`feedback`): `/feedback <text>` and the agent's `leave_feedback` store a person's words with kind, chat, message and run; the /info receipt's Report a problem (`ReportAction`, works on the ephemeral receipt too) files a report on that answer (kind `wrong_answer` / `missed_context` / `wrong_image` / `bug`, the answer's run and message; one per person per run, a second press recategorizes) and for 5 minutes (`details_until`) takes the author's next text message in the chat where they pressed (`details_chat_id`) — not a command, in groups not addressed to Derp — as its text (private: a plain line; groups: a 👌 reaction), unless they skip; one window per person (opening one closes the others; a report with text keeps it when recategorized); `details_for` runs inside `CaptureMiddleware`'s per-message transaction and hands handlers `report_id`; owners review open items with `/feedbacks` in a private chat (`from_owner`; kind, run and a link to the message where the chat has message links; 5 per page, mark done, or done + thank: a localized DM to the author, sent only by the press that closes the item, so at most once; an undeliverable DM still closes it and the owner is told). `forget_member` deletes a person's feedback from that chat.
- `owner.py`: best-effort plain DMs to `OWNER_IDS` (purchases, refunds, subscription changes, the sponsored cap, the OpenRouter key's remaining limit, model-scout changes; a ping can carry buttons — the scout's carries Apply / Ignore for each new proposal, and deciding there only drops that proposal's buttons); `ErrorTally` counts ERROR records by logger name only and `send_error_digest` posts one line per interval to `OPS_CHAT_ID` (owners' DMs when unset) with `LOGFIRE_URL`; `from_owner` — the filter on owner commands (an owner, in private; others fall through to the unknown-command reply); `is_blocked` — owner blocks (`users.blocked_at`, `chats.blocked_at`) stop every answer (runtime entry, approvals, inline, guest), storage and transcription, pause their scheduled jobs and drop their `/feedback`; other commands (including `/paysupport`) still work.
- `console.py`: owner-only, private `/stats` (listed only for owners) (provider-ledger spend by window and funding, Stars revenue and refunds, Derp fees, runs, top chats, the key's limit, live pins with Roll back, open scout proposals with Apply / Ignore), `/grant <id> <dc>` (a `grant` lot, idempotent per command message; the person is told; a chat wallet's empty-wallet line is re-armed, as by a purchase) and `/block` / `/unblock <id>` (negative ids are chats). Non-owners fall through to the unknown-command reply. Owner copy is English only. `/context [text]` works in any chat an owner is in (`owner.owner_here`): `Runtime.preview` of that message (or one saying `text`) rendered by `context.py` into one self-contained, escaped, script-free HTML page sent as a file — ephemerally in groups (owners get a per-group menu with an ephemeral /context, `owner.owner_groups` → `settings.start.publish_profile`), to the owner's private chat when typed out there, never to the chat; so it only ever shows chats an owner is in.
- `import_main.py`: the one-off cutover import from the previous Derp database (URLs from `SOURCE_DATABASE_URL` / `TARGET_DATABASE_URL`, explicit `--bot-id`, nothing from `.env`; the target must be migrated; read-only on the source; idempotent): users, chats, balances as `migration` lots ×`credits_per_star`, old chat memory as notes, the last 30 days of message text (no media files: the old schema has no `file_unique_id`). Groups still get the join notice on their first invocation. Prints counts only.
