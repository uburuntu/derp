# Ops

- `observability.py` is the only module that configures logging or Logfire. Spans carry numeric IDs, kinds, counts and outcomes; never message text, captions, tool arguments, file IDs, URLs or exception messages. The one exception is `record_run_failure`, which exports a redacted, truncated exchange.
- Logfire is optional and must fail soft. Do not instrument HTTPX/aiohttp globally — Telegram file URLs contain the bot token.
- `redaction.py` masks known secrets (from `Settings.secret_values()`) and secret-shaped strings in every log line.
- `feedback.py` + `models.py` (`feedback`): `/feedback <text>` and the agent's `leave_feedback` store a person's words with kind, chat, message and run; owners review open items with `/feedbacks` in a private chat (5 per page, mark done). `forget_member` deletes a person's feedback from that chat.
- `owner.py`: best-effort plain DMs to `OWNER_IDS` (purchases, refunds, subscription changes, the sponsored cap, the OpenRouter key's remaining limit, model-scout changes); `ErrorTally` counts ERROR records by logger name only and `send_error_digest` posts one line per interval to `OPS_CHAT_ID` (owners' DMs when unset) with `LOGFIRE_URL`; `is_blocked` — owner blocks (`users.blocked_at`, `chats.blocked_at`) stop every answer (runtime entry, approvals, inline, guest), storage and transcription, pause their scheduled jobs and drop their `/feedback`; other commands (including `/paysupport`) still work.
- `console.py`: owner-only, private, unlisted `/stats` (provider-ledger spend by window and funding, Stars revenue and refunds, Derp fees, runs, top chats, the key's limit, live pins with Roll back, open scout proposals with Apply / Ignore), `/grant <id> <dc>` (a `grant` lot, idempotent per command message; the person is told) and `/block` / `/unblock <id>` (negative ids are chats). Non-owners fall through to the unknown-command reply. Owner copy is English only.
- `import_main.py`: the one-off cutover import from the previous Derp database (read-only on the source; idempotent): users, chats, balances as `migration` lots ×`credits_per_star`, old chat memory as notes, the last 30 days of message text (no media files: the old schema has no `file_unique_id`). Groups still get the join notice on their first invocation. Prints counts only.
